WebDriverAgent 元素树控制 — 接入指南与踩坑

iphone-use 的 L2 元素层:通过 iOS 自己的辅助功能树按「元素」操作 App, 事件由手机自己合成 —— 不抢 Mac 光标、不靠视觉猜坐标、中文输入直通。这是对镜像+CGEvent(L3 像素层)的升级, 不是替代。本页记录在真机上验证出的全部坑。

为什么要这一层

镜像窗口对 macOS 来说只是一块视频,iOS 的按钮不在 Mac 的辅助功能树里,所以现状(L3)只能看图猜坐标 + 用 Mac 的真实光标代点:慢、随布局/语言/分辨率漂移、且和正在用电脑的人抢同一颗光标。WebDriverAgent(WDA,Appium 的底座)作为一个测试 runner 跑在手机上,能直接拿到 iOS 的元素树并由手机自己合成事件。

层通道本质短板
L1 动词Shortcuts / App Intents调 App 暴露的类型化动作,最快最确定只覆盖 App 愿意暴露的
L2 元素WebDriverAgent读 iOS 元素树,按元素点击,手机自己合成事件需 Xcode 签名装 runner
L3 像素镜像 + CGEvent看图猜坐标,Mac 光标代点 —— 万能兜底慢、脆、抢光标

前置条件

  • Mac:Xcode(命令行套件),并在 Xcode → Settings → Accounts 登录 Apple ID(免费 Personal Team 即可)。
  • iPhone:开启开发者模式(设置 → 隐私与安全性 → 开发者模式 → 开 → 重启)。
  • iPhone 的 iOS 版本必须 ≤ Xcode 支持的最高 iOS —— 见下方头号坑。
  • WDA 源码:git clone https://github.com/appium/WebDriverAgent.git

一次跑通的命令

cd WebDriverAgent
xcodebuild -project WebDriverAgent.xcodeproj -scheme WebDriverAgentRunner \
  -destination "platform=iOS,id=<设备UDID>" \
  -allowProvisioningUpdates \
  DEVELOPMENT_TEAM=<你的TeamID> \
  PRODUCT_BUNDLE_IDENTIFIER=com.yourname.wdarunner \
  test
# 成功标志:日志出现 ServerURLHere -> http://<phone-ip>:8100/

踩坑清单(真机验证)

① iOS 版本不能超前于 Xcode 的 DDI 头号硬坑

Xcode 自带的 Developer Disk Image(DDI)必须 ≥ 设备 iOS 版本才能挂载。装了 iOS beta 的手机配旧 Xcode,开发服务永远起不来 —— devicectl 显示 ddiServicesAvailable: false,xcodebuild 报 "Developer Disk Image is not mounted… Ensure that the device is unlocked"。注意这句和「锁屏」报错文案一模一样,极易误判成锁屏问题。

排查:plutil -p /Library/Developer/DeveloperDiskImages/iOS_DDI/version.plist 看 ProductBuildVersion(如 17A400=iOS 26.0),对比手机 设置→通用→关于本机 的版本。

修复:升级 Xcode 到能覆盖该 iOS 的版本(iOS beta 用户要装对应 Xcode beta);或别在 beta 系统的设备上跑 WDA。结论:WDA 路线要求「设备 iOS ≤ Xcode 支持的最高 iOS」。

易错点:点版本不跨大版本。 设备是 iOS 27.0(大版本)时,Xcode 26.5(DDI build 17F42 = iOS 26.5)再新也不行 —— 必须装 Xcode 27.x beta(release notes 写 "iOS 27 SDK")。Apple 年份命名下 26→27 是跨大版本。iOS 17+ 的 DDI 是设备个性化的 cryptex,由对应 Xcode 现场拉取,手动塞 DDI 的老办法对 iOS 17+ 不再适用,所以只能装对的 Xcode。

② 手机锁屏 → 开发服务起不来(另一个独立原因,文案相同)

首次挂载 DDI 必须保持手机解锁。报错与坑①完全一样,所以先排除版本不匹配,再确认是否锁屏。建议跑 WDA 期间把自动锁定调长。

③ 两套设备 ID,别搞混

xcrun devicectl list devices 显示的是 CoreDevice UUID(如 98E449E4-…);xcodebuild -destination "id=…" 要的是老式 UDID(如 00008110-001C…)。用错直接报 "Unable to find a device matching the provided destination specifier"。查正确 UDID:xcodebuild -showdestinations 或 devicectl device info details 里的 udid 字段。

④ 未登录开发团队 → 签名失败

新机器 security find-identity -p codesigning 返回 0,xcodebuild 报 "Signing for WebDriverAgentRunner requires a development team"。修复:Xcode → Settings → Accounts 登录 Apple ID;证书首次编译用 -allowProvisioningUpdates 自动生成。

⑤ 手机上要信任开发者证书

装上后首次启动若被拒,去 设置 → 通用 → VPN 与设备管理 信任你的开发者证书。

⑥ 免费账号签名 7 天过期

免费 Personal Team 签出来的 WDA 7 天失效,要每周重装;付费开发者账号(¥688/年)签名一年有效。长期部署建议付费账号。

跑通之后(验证清单)

WDA 起来后(http://<phone-ip>:8100),下列能力是这条路线相对镜像+CGEvent 的核心优势:

  • GET /source — 拿到元素树(含中文 App 的 label)。
  • 按元素点击 / POST …/value 写值 — 不碰 Mac 光标,人可同时正常用电脑。
  • type 直接送字符串 — 绕过 keycode / 拼音 IME 整个坑,中文直通。
  • 按元素 label 定位 — 无坐标漂移。
这一层不取代镜像。 镜像 + WebRTC 仍是人类远程桌面、视觉兜底、以及 WDA 覆盖不到时的保险。 agent 的默认路径优先 L1 动词 → L2 元素 → L3 像素兜底。
